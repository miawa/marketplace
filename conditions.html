Privacy Policy

Across the marketplace, the application collects limited user data and information to provide functionality and communications between sellers and buyers. While developing the system, we considered user privacy as it was crucial to how we handled user personal information across the marketplace.

Data Collection

Data collection consists of user input that facilitates the user’s ability to access and make use of the marketplace. Data collected includes:

  • Usernames
  • Email Addresses
  • Product listings
  • Home / Delivery Addresses
  • Login credentials
  • User messages and communicated data

How we use User Data

  • Create and authenticate user accounts
  • Manage user product listings in line with marketplace guidelines
  • Facilitate communication between users
  • Improve functionality using user feedback
  • Maintain security and ensure moderation practices

User Data Storage and Security

During the development process, we selected Supabase as our backend system due to its secure data protection services. We have implemented appropriate access restrictions to reduce the risk of unauthorised access.

Passwords are not stored in plain text; they are hashed and dependent on secure authentication systems provided through Supabase’s backend.

User Rights

  • Request access to their information stored by us
  • Update and remove inaccurate account details
  • Request the deletion of their accounts and any related data
  • Report inappropriate listings or harmful content

Session Data and Cookies

Our marketplace uses temporary session or cookie data to maintain login sessions and improve usability. Users are given the opportunity to choose between essential cookies or accepting all cookies including analytics.

Terms and Conditions

Acceptable Practices

  • Users must provide acceptable and accurate user information
  • Users must upload genuine product listings
  • Communication between users must be respectful
  • The platform must be used lawfully in line with guidelines

Prohibited Practices

  • Uploading illegal or inappropriate items
  • Fraudulent or misleading product listings
  • Harassing or promoting abuse of other users
  • Unauthorised access attempts to accounts or databases
  • Impersonation of other users
  • Sending inappropriate data via the messaging system

Content Moderation

Administrators possess the right to remove listings or accounts deemed in violation of marketplace guidelines ensuring user safety across the platform.

Limitation of Responsibility

Note: This marketplace is a prototype system. Users remain responsible for the accuracy of listings. We cannot guarantee the legitimacy of uploaded listings nor take responsibility for communication between users.

Future Improvements

  • Automated moderation systems
  • User reports on system functionality
  • AI detection to reduce misleading listings
  • Two-factor authentication (2FA)
  • Improved privacy controls

Accessibility Statement

We are committed to ensuring digital accessibility for all users of our marketplace. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

Conformance Status

The system is designed to follow WCAG 2.1 Level AA guidelines. This includes maintaining appropriate color contrast, providing alt text for images, and ensuring keyboard navigation for all interactive components like the messaging system and listing forms.
